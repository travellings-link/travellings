# 2026年7月 审核工作意见征集

在近期的审核工作中，我们发现了部分网站存在非全年龄段内容、非常规博客类型站点申请加入等情况，我们希望就以下内容向社区公开征集意见，欢迎大家广泛的参与。

## 准入条款

准入条款添加关于非全年龄内容与巡查处理两个板块，并对于其他内容进行格式优化，提升可读性。本次条款对已加入的站点不再根据“法不及过往”原则遵守，现有成员站也将按照现有准则执行。

> 提示：您可以通过[链接](https://travellings.feishu.cn/docx/ASVIdTFdfoPittxXkAXc4yCDnVc?from=from_copylink)查看完整草案

1. **关于非全年龄内容**

为兼顾公共展示环境及全年龄用户的观感，我们希望成员能对边缘性非全年龄内容采取相应措施，以确保使用者的体验。

```Plain Text
开往尊重每一位站长的创作自由，但也应兼顾公共展示环境及全年龄用户的观感。因此，即使内容未明显触及“限制性内容”规定，若涉及边缘性非全年龄内容，建议站长采取以下措施：
1. **显著的 NSFW 提示**：在文章页面及首页列表等入口位置，设置清晰、醒目的 Not Safe For Work（NSFW）提示，确保用户在点击前即可获知内容属性。
2. **RSS 输出隐藏**：通过技术手段（如分类、标签或插件设置）将该类文章从公共 RSS 抓取范围中移除，仅保留站内直接访问路径。
3. **降低公共曝光**：尽量避免此类内容出现在首页推荐、聚合展示或对搜索引擎可见的摘要中。
4. **其他**：其他等提示或减少传播的措施
```

2. **巡查处理**

根据《开往项目运维规定》，维护组有权通知成员进行整改，并在通知后执行删除操作。本次准入条款修订中，将新增“巡查处理”章节，明确具体处置流程，以便开往成员充分知悉相关规定。

```Plain Text
若项目组发现站点存在发布违法内容、内容农场等行为，而站点未提前告知或主动退出的，项目组将采取以下措施：
1. **警告并暂停跳转**：对首次违规且情节较轻的成员站，项目组将以邮件或 Issue 等形式发出警告，并在其完成整改前暂停该站点在开往的跳转服务。
2. **限期整改**：站长应在收到警告后14日内完成整改并回复项目组。整改通过后恢复跳转。
3. **永久移除**：对逾期未整改、重复违规，或涉及严重违法违规内容（如色情、暴力、血腥等）的站点，项目组将予以永久移除，并视情况列入黑名单；被列入黑名单的站点不再接受重新加入申请。
```

## 加入类型

开往目前仅对博客、引导页、个人主页和导航站制定了明确的准入规则，而论坛以及友链类网站（将用户引入另一个友链跳转/推荐等项目）尚未纳入现有规则体系。为了完善标准，现面向社区公开征集关于这两类站点准入的建议：

1. 您认为论坛以及作为友链类网站是否可以加入开往

2. 如可以，则您心目中应当有的审核要求是什么？
